# MiniWiki YomSprint

YomSprint é um plugin/minigame feito com a api do spigot, inspirado na prova dos 100 metros raros.  
![Spigot](https://img.shields.io/badge/Spigot-1.20.4-yellow) ![Java 21](https://img.shields.io/badge/Java-21-green)

# Sistemas:

  - Sistema de contagem de wins e PR (Personal Record)
  - Escolha de banco de dados na config (SQLITE/YAML)
  - Integração com o PlaceholderAPI
  - Mútltiplas competições simultâneas
  - Impulso com base no intervalo de clicks do player
  - Scoreboard customizável

# Comandos :
  - /run - Comando Principal
  - /run track <addlane/create/setlanelength/setmlobby/setwlobbt>
  - /run leave
