#  **YomSprint 1.20.4**

YomSprint é um plugin de Minecraft tendo de inspiração os 100m rasos.

## Comandos :
  - /run - Abre a GUI principal.
  - /run track <addlane/create/see/setlanelength/setmlobby/setwlobby> - Commando com subcomandos para gerenciar as tracks. 
  - /run leave - Sai da competição que você está.

## Sistemas:
  - Sistema de boost click
  - Sistema de PR (Personal Record)
  - Suporte ao PlacheHolderAPI
  - Multiplas competições simulatâneas  

*Track representa uma pista
